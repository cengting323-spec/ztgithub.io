# 🍎 末世动态物资管理系统

一个为 SillyTavern 设计的动态物资管理插件，具有可拖拽的悬浮界面和真实的物资变化模拟。

## ✨ 特色功能

- 🍎 **可拖拽悬浮窗** - 随意拖动到界面任何位置
- 📦 **动态物资系统** - 物资会随机出现、消失、增减
- 🎲 **随机事件模拟** - 模拟末世环境中的随机遭遇
- 🎮 **实时交互** - 点击按钮直接管理物资
- 💾 **数据持久化** - 关闭页面后数据不会丢失

## 🎯 使用方法

1. **打开界面**：点击右下角的 🍎 按钮
2. **移动窗口**：拖动标题栏到任意位置
3. **管理物资**：
   - `+1`/`-1`：精确调整数量
   - `+5`/`-5`：快速调整数量
   - `🎲 随机事件`：模拟随机遭遇
   - `➕ 获得物资`：添加新物资类型

## 📊 物资系统

### 现有物资类型
- 饮用水、压缩干粮、医疗包
- 手枪弹药、车辆燃油、电池
- 车辆、突击步枪、抗辐射剂、发电机

### 动态特性
- ✅ 物资数量会随机增减
- ✅ 数量为0时自动从列表移除  
- ✅ 会随机获得新的物资类型
- ✅ 每2分钟有30%几率触发随机事件
